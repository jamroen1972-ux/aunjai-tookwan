อัปเดตเมนูเสี่ยงโชคและแชททำนายฝัน รุ่นขยายคำค้นเลขกำลังวันและเลขตามงวด

อัปโหลดไฟล์หน้าเว็บต่อไปนี้ที่หน้าแรกของรีโปภาษาไทย aunjai-tookwan เท่านั้น:
- index.html
- sw.js
- luck-main.webp, luck-record.webp, luck-draw.webp, luck-calc.webp, luck-dream.webp, luck-sources.webp

อัปโหลด backend-worker/index.js ทับไฟล์เดิมในโฟลเดอร์ backend-worker ของรีโปเดียวกัน แล้ว Deploy Worker ใหม่

สิ่งที่ปรับ:
- ชื่อผู้ช่วยในคำตอบและเสียงอ่านแสดงเป็น “น้องอุ่นใจ”
- ปุ่มเลขวันนี้จะใช้ผลและแหล่งอ้างอิงชุดเดิมตลอดวันบนอุปกรณ์นั้น เพื่อลดผลที่เปลี่ยนไปเมื่อกดซ้ำ คำค้นจะอิงงวดถัดไปวันที่ 1 หรือ 16 ยอมรับบทความย้อนหลังได้ถึง 30 วันเมื่อระบุงวดชัดเจน
- Worker ตรวจว่ามีแหล่งเว็บอ้างอิงก่อนส่งคำตอบเลขกลับ หากไม่พบแหล่ง ระบบจะแจ้งข้อผิดพลาดในช่องแชท
- ลิงก์แหล่งที่มาที่ Gemini ส่งกลับยังแสดงใต้คำตอบเพื่อให้กดตรวจเองได้
- ปรับ Service Worker เป็น v14 เพื่อให้เว็บโหลดไฟล์ใหม่

หลัง Deploy Worker ให้ตรวจว่ามี Secret ชื่อ GEMINI_API_KEY อยู่ใน Worker เดิม ไม่ต้องนำ API key ไปใส่ในไฟล์เว็บหรือ GitHub

หมายเหตุ: การค้นเว็บช่วยเพิ่มที่มาและลดการเดา แต่ไม่ได้รับรองว่าตำราหรือเว็บต้นทางถูกต้องเสมอ ผู้ใช้ควรกดลิงก์ตรวจแหล่งก่อนเชื่อข้อมูล
