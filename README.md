# อุ่นใจทุกวัน PWA — แพ็กจากหน้าเว็บรุ่นล่าสุดที่ส่งมา

แพ็กนี้ใช้ไฟล์ `index.html` รุ่นล่าสุดที่ผู้ใช้ส่งมา ซึ่งมีเมนูหน้าหลัก 8 รายการและเมนู “เมนูอาหาร 4 ภาค” แยกหน้า พร้อมเพิ่มส่วนติดตั้ง PWA, manifest, Service Worker และไอคอน รวมถึง manifest, Service Worker, ไอคอน และปุ่มติดตั้งในเมนูด้านข้าง

## ใช้แทนไฟล์ชุดเก่าใน GitHub
1. แตก ZIP แล้วเปิดโฟลเดอร์ `dist`
2. ใน repository `aunjai-tookwan` ให้อัปโหลดไฟล์ทั้งหมดภายใน `dist` ไปที่ระดับบนสุด เพื่อแทน `index.html` และ `manifest.webmanifest` เดิม และแทน `sw.js` เดิม รวมทั้งเพิ่ม/แทนไฟล์ใน `icons`
3. คง branch `main` และ GitHub Pages folder `/(root)` ไว้ตามเดิม
4. เปิด `https://jamroen1972-ux.github.io/aunjai-tookwan/` ด้วย Chrome บน Android แล้วโหลดหน้าใหม่หนึ่งครั้ง

## เมนูอาหารไทย 4 ภาค (แยกจากสุขภาพและอาหาร)
- หน้าค้นหาและตัวกรองใช้ตามไฟล์รุ่นล่าสุดที่ส่งมา
- เพิ่มช่องค้นหาชื่อเมนูหรือวัตถุดิบ
- แสดงตัวอย่างอาหารภาคเหนือ ภาคอีสาน ภาคกลาง และภาคใต้ พร้อมหมวดจานด่วน/เมนูเส้นและโอกาส
- ปุ่มเมนูเปิดผลค้นหาสูตรหรือวิดีโอจาก Google/YouTube; รายการเป็นตัวอย่างค้นหา ไม่ใช่สูตรที่จัดเก็บในแอป

## ปุ่มติดตั้ง
- เปิดเมนู ☰ ในหน้าเว็บ แล้วแตะ **ติดตั้งแอป**
- หาก Chrome ส่งคำขอติดตั้งให้เว็บ ปุ่มจะเปิดหน้าต่างติดตั้งของ Chrome
- หากยังไม่มีหน้าต่างติดตั้ง ปุ่มจะแจ้งให้ใช้เมนู Chrome `⋮` → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก** และจะไม่ค้างอยู่ที่สถานะ “กำลังติดตั้ง”
- หากเพิ่งอัปโหลด ให้เปิดเว็บออนไลน์และโหลดซ้ำเพื่อให้ Service Worker ทำงานก่อนลองติดตั้งอีกครั้ง

## หมายเหตุ
- ต้องเปิดเว็บผ่าน HTTPS
- Service Worker แคชหน้าเว็บและไฟล์พื้นฐานเท่านั้น ฟังก์ชันที่เรียกบริการออนไลน์ยังต้องใช้อินเทอร์เน็ต
- ข้อมูลในเบราว์เซอร์โดเมนเดิมไม่ย้ายข้ามมายัง GitHub Pages โดยอัตโนมัติ
