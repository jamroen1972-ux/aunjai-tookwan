อัปเดตเว็บอุ่นใจทุกวันบน GitHub Pages

ไฟล์หลักที่แก้ไข:
- index.html: ให้เมนูผลสลากย้อนหลังเชื่อมต่อ API Worker ที่เผยแพร่แล้ว
- sw.js: เพิ่มรุ่นแคชเป็น v5 เพื่อให้ PWA รับไฟล์ใหม่

วิธีนำขึ้น GitHub:
1. แตกไฟล์ ZIP นี้
2. อัปโหลดไฟล์จากโฟลเดอร์หลักไปแทนที่ไฟล์ชื่อเดียวกันใน repository (index.html และ sw.js)
3. อัปโหลดไฟล์และโฟลเดอร์ที่เหลือในชุดนี้ด้วย หากต้องการสำรอง repository ให้ครบทั้งชุด
4. รอ GitHub Pages อัปเดต แล้วเปิดเว็บใหม่หรือปิด/เปิดเบราว์เซอร์อีกครั้ง

หมายเหตุ:
- โฟลเดอร์ backend-worker เก็บซอร์สของ Worker รุ่น 37 ไว้เป็นสำเนาอ้างอิง
- GitHub Pages ไม่ได้รัน Worker เอง เว็บจึงเรียก API จาก Worker ที่เผยแพร่ไว้ในเว็บอุ่นใจทุกวัน
- ไฟล์เว็บไซต์และไอคอนในชุดนี้คัดลอกจาก repository ปัจจุบันก่อนแก้เฉพาะสองไฟล์ข้างต้น


อัปเดตเมนูเสี่ยงโชค
- แตกไฟล์ ZIP นี้แล้วอัปโหลดไฟล์และโฟลเดอร์ทั้งหมดไปไว้ที่ root ของ repository โดยแทนที่ไฟล์เดิม
- หน้าเสี่ยงโชคแยกเป็นหน้าบันทึกซื้อ ตรวจผล แหล่งแนวทาง คำนวณชุดเลข และทำนายฝัน
- หลังอัปโหลด เปิดเว็บใหม่หรือรีเฟรชหนึ่งครั้งเพื่อให้ Service Worker รุ่นใหม่ทำงาน


อัปเดตเมนูทำนายฝันด้วย AI ฟรี
- อัปโหลด index.html และ sw.js ไปแทนไฟล์ใน root ของ GitHub Pages
- ต้องอัปเดต backend-worker/index.js บน Worker ที่เผยแพร่ API ด้วย การอัปโหลดไฟล์นี้ไว้ใน GitHub อย่างเดียวไม่ทำให้ Worker เปลี่ยน
- ตั้ง secret GEMINI_API_KEY ใน Worker; ห้ามวาง API key ในหน้าเว็บหรือใน repository
- อ่าน README_AI_CHAT_TH.txt สำหรับขั้นตอนและข้อจำกัดของโควตาฟรี
