ชุดไฟล์อัปเดตเมนูรายชื่อ — อุ่นใจทุกวัน (GitHub Pages)

วิธีนำขึ้น GitHub:
1. แตกไฟล์ ZIP นี้
2. ในหน้า Repository ของ GitHub เปิดโฟลเดอร์หลัก (root) ของ branch main
3. อัปโหลดไฟล์ index.html และ sw.js ในชุดนี้ โดยเลือกแทนที่ไฟล์เดิมทั้งสองไฟล์
4. กด Commit changes
5. เมื่อ GitHub Pages อัปเดตแล้ว เปิดเว็บใหม่ด้วย Chrome บน Android และเข้าเมนูรายชื่อ > จัดการ/บันทึกรายชื่อ > เลือกจากสมุดรายชื่อ

หมายเหตุ:
- เลือกผู้ติดต่อได้หลายคนต่อครั้ง และเลือกหมวดหมู่ที่จะจัดเก็บได้
- รายชื่อที่เบอร์ซ้ำกับข้อมูลเดิมจะถูกข้าม
- เบราว์เซอร์จะแสดงหน้าต่างให้ผู้ใช้เลือกผู้ติดต่อเอง เว็บไม่อ่านหรือส่งสมุดรายชื่อทั้งหมดขึ้นเซิร์ฟเวอร์
- รายชื่อที่นำเข้าบันทึกไว้ในข้อมูลของเว็บบนเบราว์เซอร์เครื่องนี้
- ต้องใช้ Chrome บน Android และเปิดเว็บผ่าน HTTPS; Contact Picker API ไม่รองรับทุกเบราว์เซอร์
