# อัปเดตเมนูทำนายฝันด้วย AI ฟรี

## สิ่งที่เพิ่ม
- หน้าแชททำนายฝัน หน้าตาและวิธีใช้ใกล้กับหน้าแชท Vios K
- พิมพ์ข้อความหรือแตะไมโครโฟนเพื่อพูด (รองรับเบราว์เซอร์ที่มี Speech Recognition)
- AI ตอบเป็นภาษาไทย และมีปุ่มอ่านข้อความเป็นเสียง
- เก็บประวัติสนทนาไว้ระหว่างเปิดหน้าเว็บครั้งนั้น
- แยกคำตอบที่ AI สร้างออกจากชุดเลขที่มีแหล่งอ้างอิงเดิม ไม่อ้างเลขที่ AI คิดขึ้นว่าเป็นเลขจากเว็บไซต์
- ใช้ Gemini API รุ่นฟรีผ่าน Worker และเก็บ API key ไว้ฝั่ง Worker

## วิธีนำขึ้น GitHub Pages
1. แตกไฟล์ ZIP
2. อัปโหลดไฟล์ใน root ของชุดนี้ไปแทนไฟล์เดิมใน root ของ repository โดยเฉพาะ `index.html` และ `sw.js`
3. อัปโหลดโฟลเดอร์ `backend-worker` และไฟล์ประกอบตามชุดไว้เป็นสำเนาซอร์สใน repository
4. รอ GitHub Pages อัปเดต แล้วปิด/เปิดเว็บใหม่ หรือรีเฟรชหน้า

## สิ่งที่ต้องทำฝั่ง Worker เพื่อให้ AI ตอบได้
GitHub Pages เป็นเว็บสแตติก จึงไม่สามารถรัน API key หรือ Worker ได้เอง การอัปโหลด `backend-worker/index.js` ขึ้น GitHub อย่างเดียวจะยังไม่เปิดใช้งาน API ต้องอัปเดต Worker ที่ให้บริการ API อยู่แล้วด้วย

1. สร้าง API key ของ Gemini ใน Google AI Studio: https://aistudio.google.com/app/apikey
2. ตั้งค่า Worker secret ชื่อ `GEMINI_API_KEY` แล้วใส่ key ในหน้าจัดการ secret ของบริการ Worker ที่ใช้งานอยู่ ห้ามใส่ key ลงใน `index.html`, GitHub หรือส่ง key ในแชท
3. นำซอร์ส `backend-worker/index.js` รุ่นนี้ไปอัปเดต Worker ที่ให้บริการ `https://aunjai-tookwan.comment-viscera-8sw4.chatgpt.site`
4. ใน Worker ตั้งค่า `GEMINI_MODEL` เป็น `gemini-3.8-flash` ได้ (ถ้าไม่กำหนด ระบบใช้ค่านี้เป็นค่าเริ่มต้น)
5. ทดสอบส่งข้อความจากหน้าแชททำนายฝัน

## เรื่องโควตาและความเป็นส่วนตัว
Google ระบุว่า Gemini API มีโควตาฟรีจำกัดตามรุ่นโมเดลและโปรเจกต์ ไม่ใช่การใช้งานได้ไม่จำกัด และคำขอ/คำตอบที่ใช้โควตาฟรีอาจถูกนำไปปรับปรุงผลิตภัณฑ์ได้ จึงแสดงข้อความแจ้งในหน้าแชทและไม่ควรส่งข้อมูลส่วนตัวหรือข้อมูลลับ

## ไฟล์ที่แก้
- `index.html` — UI แชทและการเรียก `/api/dream-chat`
- `sw.js` — เพิ่มรุ่น cache เป็น v8 เพื่อรับไฟล์ใหม่
- `backend-worker/index.js` — API Worker ที่เชื่อม Gemini และอ่าน secret จาก `GEMINI_API_KEY`
